**Clon de la Interfaz de Netflix**

**Descripción**

Este proyecto consiste en la réplica visual y detallada de la interfaz de usuario de Netflix. Se ha desarrollado utilizando únicamente HTML y CSS puros, logrando un diseño fiel y optimizado para navegadores modernos.

**Tecnologías Usadas**

**HTML5**:Estructuración del contenido. 

**CSS3**: Diseño, maquetación y estilos visuales.

**Editor**: Desarrollado utilizando Visual Studio Code.

**Características Principales**

Interfaz adaptable y responsiva. Diseño visual basado en la plataforma original. Secciones informativas y de preguntas frecuentes implementadas.

**Cómo Visualizar**

Para ver el proyecto en funcionamiento, simplemente descarga los archivos y abre el archivo index.html en tu navegador web de preferencia.
